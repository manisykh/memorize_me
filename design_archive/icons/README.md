# Memorize Me Launcher Icon Sources

- `memorize_me_v4_original.png`: original V4 rounded preview.
- `memorize_me_v4_legacy_opaque.png`: opaque cream-background source for legacy launchers.
- `memorize_me_v4_adaptive_foreground.png`: transparent foreground for Android adaptive icons.
- `memorize_me_v4_play_512.png`: opaque 512 x 512 PNG for the Play Console store listing.
- `memorize_me_before_v4_20260715.png`: icon used before V4.

The generated Android launcher resources remain under
`android/app/src/main/res/`. Run `dart run flutter_launcher_icons` after
changing one of these source files.
