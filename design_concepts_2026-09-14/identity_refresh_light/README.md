# Memorize Me — 통합 라이트 디자인 시안

첨부한 네 화면을 시각 기준으로 삼아 온보딩부터 학습·관리·설정까지 31개 화면을 한 시스템으로 정리했다. 이 폴더는 **시안 전용**이며 Flutter 앱 코드는 변경하지 않았다. `*_reference.png` 네 파일은 사용자가 제공한 기준 화면이고, 나머지는 같은 규칙으로 새로 제작한 시안이다.

## 아이덴티티

- 배경은 순백색, 본문은 딥 네이비 `#0C1B36`, 주요 이동·선택·확인은 코발트 블루 `#1764E8`.
- 에메랄드 `#117A5A`는 정답·완료, 코럴 `#D94B3B`은 오답·주의, 바이올렛 `#6B4FD7`은 AI 생성 동작, 앰버 `#E58917`은 사용 안내·일정에만 사용한다.
- 카드보다는 여백과 타이포그래피로 구분한다. 그룹형 행은 1px 차가운 회색 경계와 12–16px 모서리. 아이콘은 얇은 선형으로 통일한다.
- 중첩 카드, 어두운 강조 패널, 그라데이션, 유리 효과, 마스코트, 장식성 AI 그래픽은 사용하지 않는다.
- 기본 탭은 홈·복습·통계·달력·AI 학습·설정 여섯 개. 세부 작업에서는 하단 탭을 숨기고 뒤로 가기와 한 개의 주요 동작에 집중한다.
- 플래시카드 뒷면의 `몰라요`·`알아요` 버튼에 세션 통계를 직접 결합한다. 복습할 단어가 0개면 시작 버튼은 비활성이다.

## 제작·검토 메모

제작 방식은 Product Design의 이미지 시안 절차와 기본 제공 Image Gen 도구다. 공통 프롬프트는 `390 × 844 모바일 앱 내용만`, 첨부한 네 장의 흰 배경·남색 타이포·코발트 CTA·의미별 강조색·얇은 테두리·절제된 아이콘을 엄격히 따르고, 각 파일명에 해당하는 기능과 실제 앱의 한글 라벨을 배치하도록 했다. 각 화면은 별도 호출로 제작했다. 날짜가 등장하는 시안은 2026년 9월 14일을 기준으로 검토했다.

이미지의 문구·수치·프로필 사진은 시안용 예시이며, 최종 구현 전에 실제 데이터·접근성·화면 크기별 레이아웃 확인이 필요하다. 이번 묶음은 제공된 네 기준 화면에 맞춘 **라이트 모드**다. 다크 모드는 이 색의 역할과 컴포넌트 규칙을 유지한 별도 시안으로 확장할 수 있다.
