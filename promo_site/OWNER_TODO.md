# 홈페이지 운영자 확인 항목

홈페이지 리빌딩 과정에서 임의로 만들지 않고 운영자 결정 또는 실제 자료를 기다리는 항목입니다.

## 출시 전에 필요

- [x] `단어장 가져오기`, `플래시카드`, `객관식 퀴즈`, `스펠링 퀴즈`, `시험지 만들기` MP4 영상을 홈페이지에 연결했습니다.
- [ ] **첫 학습 전용 영상**을 준비합니다. 특정 학습 방식 전체가 아니라 `학습 탭 진입 → 단어장 선택 → 학습 방식 선택 → 시작 버튼`까지만 6~10초로 녹화합니다.
- [ ] **오늘 복습 전용 영상**을 준비합니다. `오늘 복습 진입 → 카드 응답 → 완료 결과와 다음 복습 일정 확인` 흐름을 6~10초로 녹화합니다.
- [ ] **오답노트 전용 영상**을 준비합니다. `오답노트 진입 → 틀린 단어 확인 → 다시 학습 시작` 흐름이 한 번에 보이도록 6~10초로 녹화합니다. 홈페이지에는 영상이 들어갈 자리를 먼저 만들고 현재 앱 화면을 임시로 표시했습니다.
- [ ] 홈페이지 통합 학습 구역의 **복습하기 영상**을 준비합니다. 위의 오늘 복습 영상과 같은 파일을 사용할 수 있으며, `promo_site/public/media/video/review.mp4`로 전달하면 됩니다.
- [ ] 오답노트 영상은 `promo_site/public/media/video/mistakes.mp4` 이름으로 전달합니다. 다른 영상과 동일하게 앱 밖의 상태 표시줄·내비게이션 영역은 편집 과정에서 제외합니다.
- [ ] 제공된 MP4 5개를 WebM으로 추가 압축합니다. 파일당 목표 용량은 1.5MB 이하이며 MP4는 Safari·구형 브라우저용 대체 파일로 유지합니다.

- [ ] 최신 밝은 테마의 **Google Sheets 시트 선택 실제 앱 캡처**를 준비해 `public/media/feature/sheet-selection-current.svg`를 교체합니다.
- [ ] 출시 알림 수집 방식을 확정합니다. 현재는 `NEXT_PUBLIC_SUPPORT_EMAIL`이 있으면 해당 이메일로 알림 신청 메일을 보내도록 연결했습니다.
- [ ] Google Play 주소가 발급되면 Netlify의 `NEXT_PUBLIC_GOOGLE_PLAY_URL`에 등록합니다. 등록 후 주 CTA는 자동으로 `Google Play에서 받기`로 바뀝니다.
- [ ] 다음 FAQ의 정확한 운영 답변을 확정합니다: 오프라인 학습 범위, 단어장 크기 제한, 기기 변경 시 데이터 이전 방법.
- [ ] 이용약관 문서가 필요한지 결정합니다. 실제 문서가 없으므로 현재 푸터에는 빈 이용약관 링크를 만들지 않았습니다.

## 운영 정책

- [ ] iOS 미출시 방침이 바뀌면 FAQ의 `iPhone에서도 사용할 수 있나요?` 답변을 수정합니다.
- [ ] 방문·CTA 클릭 분석 도구를 추가할 경우 수집 항목을 개인정보 처리방침에 먼저 반영합니다.
- [ ] 출시 후 실제 사용자 후기나 검증 가능한 사용 지표가 생기면 신뢰 근거 구역 추가를 검토합니다.
