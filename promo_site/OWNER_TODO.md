# 홈페이지 운영자 확인 항목

홈페이지 리빌딩 과정에서 임의로 만들지 않고 운영자 결정 또는 실제 자료를 기다리는 항목입니다.

## 출시 전에 필요

- [ ] 최신 밝은 테마의 **Google Sheets 시트 선택 실제 앱 캡처**를 준비해 `public/media/feature/sheet-selection-current.svg`를 교체합니다.
- [ ] 출시 알림 수집 방식을 확정합니다. 현재는 `NEXT_PUBLIC_SUPPORT_EMAIL`이 있으면 해당 이메일로 알림 신청 메일을 보내도록 연결했습니다.
- [ ] Google Play 주소가 발급되면 Netlify의 `NEXT_PUBLIC_GOOGLE_PLAY_URL`에 등록합니다. 등록 후 주 CTA는 자동으로 `Google Play에서 받기`로 바뀝니다.
- [ ] 다음 FAQ의 정확한 운영 답변을 확정합니다: 오프라인 학습 범위, 단어장 크기 제한, 기기 변경 시 데이터 이전 방법.
- [ ] 이용약관 문서가 필요한지 결정합니다. 실제 문서가 없으므로 현재 푸터에는 빈 이용약관 링크를 만들지 않았습니다.

## 운영 정책

- [ ] iOS 미출시 방침이 바뀌면 FAQ의 `iPhone에서도 사용할 수 있나요?` 답변을 수정합니다.
- [ ] 방문·CTA 클릭 분석 도구를 추가할 경우 수집 항목을 개인정보 처리방침에 먼저 반영합니다.
- [ ] 출시 후 실제 사용자 후기나 검증 가능한 사용 지표가 생기면 신뢰 근거 구역 추가를 검토합니다.
