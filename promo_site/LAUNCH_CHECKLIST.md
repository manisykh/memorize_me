# Memorize Me 홈페이지 출시 체크리스트

이 문서는 홈페이지에 자리는 마련했지만 실제 자료나 최종 정책이 필요한 항목을 기록합니다.
이미지는 사용자의 사전 확인 없이 교체하지 않습니다.

## 사용자가 꼭 해야 할 일

- [ ] Google Play 공개 URL 확정 후 Sites 환경변수 `NEXT_PUBLIC_GOOGLE_PLAY_URL`에 등록
- [ ] 15–30초 실제 사용 영상 제작 후 공개 URL을 `NEXT_PUBLIC_DEMO_VIDEO_URL`에 등록
- [ ] 공개할 고객지원 이메일을 `NEXT_PUBLIC_SUPPORT_EMAIL`에 등록
- [ ] 베타 테스터 후기 2개 이상 확보: 문구와 홈페이지 공개 동의를 함께 받을 것
- [ ] 스토어 별점·사용자 수는 검증 가능한 수치가 생긴 뒤에만 홈페이지에 추가
- [ ] Google Sheets 권한 오류를 설명할 실제 사례나 캡처가 필요하면 별도 상세 가이드 자료 제공

## 이미지 관련 — 다음 단계에서 사용자 확인 필요

- [ ] 대표 홈 화면을 다른 데이터가 채워진 캡처로 바꿀지 사용자에게 먼저 확인
- [ ] 3단계 사용 영상 또는 GIF의 표지 이미지를 추가할지 사용자에게 먼저 확인
- [ ] 현재 PNG 화면을 WebP 또는 AVIF로 재압축할지 사용자에게 먼저 확인

현재 홈페이지 이미지는 모두 기존 최신 UI 자산을 유지합니다. 이번 개선에서는 교체하거나 재가공하지 않았습니다.

## 현재 구현을 근거로 확인한 문구

- Google Sheets·CSV·XLSX와 기본 학습 기능 무료
- 광고 없이 제공
- Google Sheets 연결 시에만 Google 로그인 필요
- Android 출시 준비 중, iOS는 현재 미제공
- AI 기능은 개인 API 키가 필요한 선택 기능

정책이나 출시 범위가 달라지면 홈페이지 FAQ와 첫 화면 문구도 함께 수정해야 합니다.
