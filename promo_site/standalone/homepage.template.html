BEFORE YOU START

자주 묻는 질문

어떤 파일 형식을 가져올 수 있나요?＋

Google Sheets와 기기에 저장된 CSV·XLSX 파일을 가져올 수 있습니다. 앱 안에서 단어장을 새로 만드는 것도 가능합니다.

Google Sheets를 수정하면 어떻게 반영되나요?＋

Google Sheets에서 수정한 뒤 앱에서 해당 단어장을 다시 동기화하면 변경 내용을 반영할 수 있습니다.

AI 연결 없이도 공부할 수 있나요?＋

네. 단어장 가져오기, 플래시카드, 퀴즈와 복습 기능은 AI 연결 없이 사용할 수 있습니다.

지원 기기와 비용은 어떻게 되나요?＋

현재 Android 출시를 준비하고 있습니다. 기본 학습 기능은 무료이며 AI는 사용자가 발급한 API 정책과 비용이 적용됩니다.
