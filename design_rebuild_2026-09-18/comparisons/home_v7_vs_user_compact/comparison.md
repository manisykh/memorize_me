# 홈 시안 비교

## 결론

실제 구현 기준은 첨부된 컴팩트 시안의 크기와 밀도를 사용하고, 보조 영역의 시각적 처리·아이콘 일관성·텍스트 대비·단어장 캐러셀은 7차 시안의 원칙을 결합하는 것이 가장 적합하다.

## 첨부 컴팩트 시안

- 장점: 실제 휴대폰 화면에 가까운 크기, 빠르게 보이는 핵심 CTA, 효율적인 세로 공간, 안정적인 단어장 선택부.
- 개선: 상태·학습 결과·다음 일정이 모두 박스로 묶여 다시 촘촘해 보임, 작은 보조 글자와 하단 탭의 접근성 확인 필요, 두 번째 단어장 카드 노출 폭이 큼, 채움/선형 아이콘이 혼용됨.

## 7차 시안

- 장점: 핵심 학습 영역의 우선순위가 분명함, 보조 영역이 구분선 중심이라 가벼움, 텍스트 대비와 아이콘 체계가 안정적임, 캐러셀 잘림이 의도적으로 보임.
- 개선: 제목·진행 링·CTA가 실제 390dp 화면 기준으로 과대해 전체 화면이 길어짐, 상단 브랜드와 프로필의 비중이 큼.

## 권장 결합안

1. 첨부안의 전체 스케일과 상단 높이를 기준으로 한다.
2. 현재 단어장 선택부는 첨부안처럼 컴팩트하게 유지하되 실제 계정 프로필 이미지를 보존한다.
3. 진행 링은 첨부안 크기를 사용하고 CTA는 최소 48dp 높이를 확보한다.
4. 상태 요약은 7차 시안처럼 선형 아이콘과 얇은 구분선으로 통일한다.
5. `오늘 학습을 마치면`과 `다음 학습`은 굵은 카드 테두리 대신 흰 바탕·구분선 중심으로 처리한다.
6. 일정은 `내일`과 `9월 20일 일요일`을 같은 행의 한 묶음으로 표시한다.
7. 활성 단어장 카드는 약 88~90% 폭, 다음 카드는 약 8~10%만 노출한다.

## 검증 한계

이미지 비교만으로 실제 터치 영역, 동적 글자 크기, 스크린리더 읽기 순서, 정확한 명도 대비 수치는 확인할 수 없다. 구현 후 실제 기기에서 별도 검증한다.
