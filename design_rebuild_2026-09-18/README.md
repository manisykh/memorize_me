# Memorize Me 디자인 리빌딩 — 단기 프로젝트

상태: 반복 고정 상단바를 제거한 2차 탭 시안과 가독성·밀도·일정·아이콘을 정리한 7차 홈 대시보드 시안 제시, 구현 전 검토 단계. 앱 코드 미변경.

## 변경 원칙

1. 기존 기능, 데이터 의미, 이동 경로와 동작을 사용자 승인 없이 바꾸지 않는다.
2. 승인된 시안의 구성·간격·색감·타이포그래피와 실제 구현의 일치도를 우선한다.
3. 더 나은 UI는 제안으로 구분해 제시하고, 승인 후 반영한다.
4. 예시 수치·계정 상태·AI 연결 상태는 실제 데이터가 아니며 구현 시 현재 앱 상태에 연결한다.
5. 각 화면을 선정 → 구현 → 실제 기기 캡처 비교 → 기능 회귀 확인 순서로 마무리한다.

## 1차 상단바 검토안 (2차 시안으로 대체됨)

- **공통으로 유지:** 테마 순환 버튼, 앱 제목, 프로필 버튼, 하단 6개 탭의 위치와 동작.
- **홈·복습·통계·달력·AI 학습:** 현재 학습 기준을 상단에 표시하고 기존처럼 탭하면 단어장 관리로 이동한다. 아래 화살표 대신 이동을 뜻하는 오른쪽 화살표를 사용한다.
- **통계·달력:** 화면 내부의 기존 범위 전환은 유지한다. 상단의 학습 기준은 범위 전환기가 아니라 단어장 관리 진입점이다.
- **설정만 별도 제안:** 상단의 학습 기준을 작은 `앱 설정` 문맥 표시로 바꾸고, 같은 단어장 관리 진입점을 설정 본문 첫 행에 둔다. 진입 위치가 바뀌므로 사용자 승인 전에는 구현하지 않는다.

## 검토가 필요한 시안상의 차이

- **공통 상단:** 현재 코드에서는 앱 제목과 학습 기준 표시를 감싼 영역 전체를 탭하면 단어장 관리로 이동한다. 시안에서 두 요소가 분리되어 보이더라도, 승인 없이 제목 탭 동작을 제거하지 않는다.
- **홈:** 시안의 `4/12`, 연속 학습일, 예상 소요 시간은 예시다. 실제 홈은 완료·잔여 개수를 계산하고, 추천 행동의 제목과 목적지를 복습 → 새 단어 → 학습 중 카드 → 전체 카드 순서로 정한다. 학습 계획 상태 카드와 단어장 현황 페이지도 현재 존재하므로 첫 화면에 안 보인다는 이유로 제거하지 않는다.
- **복습:** 시안은 객관식·스펠링을 `셀프 테스트` 한 행으로 표현한다. 실제 `QuizScreen` 진입과 `BundleHistoryPanel`의 단어장 공부 현황, 누적 오답 노트, SRS 이동은 유지한다.
- **통계:** 시안에 그려진 네 지표 카드(오늘 복습·새 단어·학습 중·안정 기억)는 현재 `_showStatsMetricCards = false`로 숨겨져 있다. 시안 그대로 노출할지는 사용자 승인이 필요하다. 현재 통계의 계획 범위 전환, `StudyPlanPanel`, 전체 암기율, SRS 이동은 유지한다. 참고 이미지의 주간 학습일/정답률 상세는 이번 구현 범위로 확정하지 않았다.
- **달력:** 시안은 월요일 시작이지만 현재 `StudyCalendar`는 일요일 시작이다. 요일 시작 변경은 별도 승인 대상이다. 실제 날짜별 완료 세션·모드 범례·SRS/플랜 표시·복습 시작·저장 오류 재시도는 이미지에 보이지 않아도 유지한다. 참고 이미지의 중복 선택 표현만 단일 선택 날짜로 바로잡았다.
- **AI 학습:** 시안의 `생성 준비 완료`는 예시 상태다. 실제 API 키 등록 여부, 베타 안내, 자동 대체 정책에 따라 문구가 달라져야 한다.
- **설정:** 단어장 관리 진입점의 상단 → 본문 재배치는 선택 가능한 UI 제안이다. 기존 다섯 설정 그룹과 테마 세 가지는 그대로 둔다.

## 다음 단계

사용자가 2차 상단 구조와 첫 구현 화면을 선택한다. 화면별 구현 후 원본 시안과 실제 기기 캡처를 나란히 비교하고, 기존 동작 회귀를 확인한다. 다크 모드와 시력 보호 테마도 각 화면 구현 시 함께 점검한다.
